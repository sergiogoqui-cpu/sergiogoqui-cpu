I build and operate production backend systems end to end — from data
model to deployment to the monitoring that tells me when something's
wrong. Most of my work is under private client repos, so this profile
leans on public code where it exists and plain descriptions where it
doesn't.

## Currently building

- **SaaS platforms** — booking systems, real-estate marketplaces, and
  admin/CRM tooling on Next.js + PostgreSQL, deployed on Vercel with
  CI gating every merge.
- **Trading & quant automation** — a MetaTrader5 execution bot with a
  statistical validation layer (walk-forward, deflated Sharpe ratio,
  Monte Carlo drawdown) built to catch backtest overfitting before it
  reaches a live account.
- **Operational tooling** — deployment health auditing, webhook
  integrations (Shopify, WhatsApp Business), and small infra scripts
  that remove a recurring manual step.

## Featured

**[strategy-robustness-kit](https://github.com/sergiogoqui-cpu/strategy-robustness-kit)**
— statistical robustness testing for trading backtests: Deflated
Sharpe Ratio, walk-forward validation, Monte Carlo drawdown resampling,
and purged/embargoed k-fold CV. Extracted from a real trading system
into a standalone, tested package.
[![CI](https://github.com/sergiogoqui-cpu/strategy-robustness-kit/actions/workflows/ci.yml/badge.svg)](https://github.com/sergiogoqui-cpu/strategy-robustness-kit/actions/workflows/ci.yml)

**[vercel-guardian](https://github.com/sergiogoqui-cpu/vercel-guardian)**
— a Vercel deployment/config auditor for CI: catches broken production
deployments, missing analytics, and config drift, with secret
redaction built into every report it writes.
[![CI](https://github.com/sergiogoqui-cpu/vercel-guardian/actions/workflows/ci.yml/badge.svg)](https://github.com/sergiogoqui-cpu/vercel-guardian/actions/workflows/ci.yml)

**[graphify-template](https://github.com/sergiogoqui-cpu/graphify-template)**
— a Claude Code project template pre-wired with a knowledge-graph
extraction skill: point it at any codebase and get a queryable graph
of its architecture back.
